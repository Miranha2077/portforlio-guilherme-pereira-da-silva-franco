# 📽️ Paginas em HTML Com Bootstrap 5
 
## 🗒️Descrição do Projeto 
A História dos Video Games é um site desenvolvido para documentar e apresentar a trajetória dos jogos eletrônicos, desde seus primeiros experimentos e consoles pioneiros até as tecnologias atuais, destacando as inovações, os títulos mais icônicos e o impacto cultural de cada período. 
 
Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End 
Para Web (2026.2)**, "este website foi construído para demonstrar na prática a estruturação semântica em HTML5, estilização avançada com variáveis CSS e design responsivo, além da integração de microaplicações interativas em JavaScript puro com bibliotecas externas como Bootstrap 5 e Chart.js.
 
## 🔎Tecnologias Utilizadas 
* **Linguagem:** HTML5, CSS
* **Ferramentas:** VSCode
* **Framework Front-End:** Bootstrap 5.3.3 (utilizado via CDN)
* **Visualização de Dados:** Chart.js 4.4.1
* **Modelo de IA:** Claude Sonnet 5.5
 
## 📒Resultados e Aprendizados 
O projeto alcançou resultados sólidos em ambiente de teste, demonstrando 
a eficácia do modelo híbrido. 
* **Gerenciamento de Estado e Tema:** Implementação de um sistema dinâmico de modo claro/escuro via JavaScript, respeitando o padrão nativo do sistema do usuário (prefers-color-scheme) e persistindo escolhas manuais com segurança por meio de localStorage.
* **Resiliência e Fallbacks:** Concepção de páginas preparadas para falhas de carregamento de CDNs externas, integrando alternativas estruturais (como tabelas textuais substitutas caso o Chart.js falhe) e validações robustas de formulários.
